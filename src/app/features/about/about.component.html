ABOUT ME

Engineering software for systems that cannot fail silently.

I graduated with a B.Tech in Civil Engineering from Sri Venkateswara College of Engineering (SVCE), Tirupati. My transition from physical infrastructure to software systems was a deliberate pivot: shifting focus from concrete and steel to the software layers that operate public infrastructure.

Since June 2024, I have been working as an Associate Software Developer at Trinity Mobility in Bengaluru. My code operates inside mission-critical public-safety platforms: Computer-Aided Dispatch for emergency response numbers (Namma112 and Maharashtra 112), a state disaster early-warning platform (Kerala Warnings, Crisis & Hazard Management System), and municipal centralized lighting infrastructure.

Enterprise civic systems operate under strict expectations of availability and consistency. A dispatch event cannot be dropped, weather warning feeds must be ingested despite fluctuating upstream schemas, and streetlight telemetry must be reliably aggregated over intermittent network connections.

My day-to-day work centers on Java, Spring Boot, Angular, and Microsoft SQL Server. I develop and maintain REST APIs, design database schema operations, optimize complex SQL queries and stored procedures, and integrate third-party services—ranging from real-time WhatsApp Business API webhooks to multi-source weather telemetry.

Production support, log analysis, and root-cause debugging are regular parts of my engineering workflow. When an issue occurs, I trace execution flow across frontend Angular components, Spring Boot microservices, database stored procedures, and external network webhooks to isolate and rectify the underlying cause.

In addition to enterprise platforms, I independently designed, built, and shipped the commercial business website for LANS Lift ↗ end to end. I managed the complete project lifecycle: initial requirements gathering, responsive frontend engineering in Angular, Git repository setup, AWS cloud deployment, DNS configuration, and production maintenance.

I am open to conversations about backend and full-stack engineering roles where scalable service architecture, rigorous data consistency, and reliable system operations are valued.
